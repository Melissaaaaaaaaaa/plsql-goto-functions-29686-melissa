# Assignment Reflection & AI Usage

## 1. GOTO vs. Structured Constructs
While PL/SQL supports the unconditional branching statement GOTO, its usage can quickly lead to unmaintainable "spaghetti code." During Part A, restructuring code into structured IF-ELSIF and CASE constructs improved readability, ensured branch predictability, and avoided illegal control transfers across block boundaries.

## 2. Using Functions in SQL Queries
Stored functions that are read-only and free from DML statements can be seamlessly embedded into SQL queries (e.g., in SELECT and WHERE clauses). This allows calculations like annual pay, tax, and department name resolution to be computed directly alongside row retrieval.
